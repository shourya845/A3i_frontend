## Brand implementation

- Use the supplied A3i logo at `public/logo.png`; no replacement logo was drawn.
- Primary surfaces use black and dark blue: `#020a12`, `#0b223c`, `#102c4d`.
- White text, white form controls and neutral blue-gray surfaces support legibility. This interprets “black and dark blue only” as the brand/chromatic palette, not a prohibition on white text. Confirm this interpretation with the assignment owner if literal two-color output is required.
- Navbar, login, Why A3i and the platform call button no longer use bright cyan, red, purple or gold accents.
- Status badges retain their explicit Live / Early access labels while using neutral colors.
- Photographs retain their original colors at the user's explicit request. No image files are modified. This is an intentional exception to strict two-color visual output; the interface surfaces and accents use the dark brand palette.
- Colored decorative background images were removed from platform/Why A3i/product-stage surfaces. Layout, interactions and backend behavior are preserved.

This is a review of the shared shell, homepage and login presentation. Imported HTML can include additional legacy styles and live tools; it is not certified as a complete brand audit of every imported page.
