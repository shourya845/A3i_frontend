# Retired design reference

These files preserve useful work from an earlier homepage option. They are documentation, not application imports.

- `platform-workflow.tsx.txt`: the unused Documents / Meetings / Translation tabbed illustration, including its example copy, keyboard navigation and reduced-motion behavior. The approved homepage uses `src/components/home/platform-intro.tsx` instead.
- `retired-homepage-styles.css.txt`: styles removed for that illustration and earlier hero/portfolio layouts. They must not be imported into the current site.

The cleanup also removed empty scaffold files: six `.placeholder` route/metadata files; empty company, FAQ and workflow content modules; empty utility, validation, lead/product type and server grounding/model/lead modules; empty demo CTA, responsible AI and product card/detail components; and three empty test files. These contained no implementation or reference information. Add real modules and tests when their features require them.

Active backend proxy code, dynamically imported chat/motion modules, original imported page content, assets, integration setup and project requirements were retained. A local recovery snapshot and declaration-removal log are available under the ignored `.tmp/cleanup-backup/` folder.
